# Mundial de Clubes FIFA — variantes visuales

Ambas imágenes representan diseños físicos distintos de la misma competición del catálogo MF LEGACY (**ID original FM: `121092`**). No se crea otro ID de Football Manager ni se duplica su palmarés.

- **2005–2023:** trofeo clásico, ilustración disponible en `Trofeos identificados/Variantes historicas/FIFA/Mundial de Clubes FIFA 2005-2023.png`.
- **2025 en adelante:** nuevo diseño dorado, ya existente en `Trofeos identificados/Pendientes de identificar/121092.png`.
- La edición inaugural **2000** tuvo otro diseño, no incluido. **2024** corresponde a la Copa Intercontinental FIFA, no a una edición del Mundial de Clubes FIFA.
